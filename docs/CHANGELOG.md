## 1.2.0——分享长视频链路打通 + 专注插件版

用户分享的超长视频不再被拒收——打通"截断观看"完整链路；同时项目完成独立身份定型与开源协议落地，专注维护 AstrBot 插件版。

### 优化项目

**分享长视频**

- 用户主动分享的超长视频不再被时长上限整条拒收：自动截断观看前几分钟，并在回复中如实告知用户"只看了开头"。
- 分享视频超过大小上限时同样走截断下载，不再直接拒收；分享失败时明确禁止 Agent 自行搜索替代视频发给用户。
- 分享视频的卡片标题与实际内容不符时，Agent 先就这条视频本身展开讨论，不擅自替对方另找视频。

**安装体验**

- 一键安装 Playwright 新增国内镜像自动回退：官方源失败时自动切换国内源重试。
- Node.js 安装在非系统路径（nvm、手动解压等）时自动搜索常见安装位置，不再要求手动填写路径。
- 远程浏览器配套部署仓库上线：远程主机端与云服务器端各有一键部署脚本，插件的远程配置项自动填写。

**主动消息**

- 主动消息排程优化：其它平台的纯文字消息不再压制抖音端的主动消息排程，两端各自独立。

### 修复项目

- 修复超长视频的时长一致性校验误杀合法截断下载的 bug。
- 修复特定分辨率（奇数高度）视频压缩静默失败、回退慢速链路的 bug。

### 重大变更（BREAKING）

- 移除独立运行版（standalone）：删除独立引擎入口与独立 Web 管理界面，本仓库今后只维护 AstrBot 插件版。
- 开源协议定型为 AGPL-3.0（自 1.0.0 起生效）；上游 MIT 基线的原文与署名保留于 LICENSE-MIT。
## 1.1.0——指令搜索视频

一句话让搜就开搜：新增按关键词搜索视频并逐条观看、转述、发卡片、聊观后感的完整链路；远程浏览器部署时视频压缩移至远程主机执行，全链路执行速度提升 4 倍。

### 新增功能

**指令搜索视频**

- 新增关键词搜索：一句话即可搜索抖音视频，逐条观看并转述、发送视频卡片、聊观后感。
- 新增异步搜索逻辑：Agent 收到搜索指令后先秒回确认，结果逐条送达，避免全部搜完才回复用户造成超长等待。
- 新增连看指令：如"搜 XX，看 5 条"——每看完一条立刻聊一条，不等到最后才总结回复；"再看一条"接续同关键词。
- 搜索结果先发视频卡片再聊观后感，让用户始终知道 Agent 在聊哪条视频。
- 新增跨平台搜索：支持在 QQ 等其它平台指令 Agent 搜索抖音视频，不必每次都打开抖音私信。

### 优化项目

**观看质量**

- 观看去重：已看过的视频直接跳过，连页面都不打开，节约 CPU 与内存资源；搜索结果乱序观看并自动翻页，不再固定按顺序观看，防止重复撞车。
- 优化超长视频的处理逻辑：不再整条拒绝，改为截断只看前几分钟，并在回复中明确告知用户"只看了开头"。
- 优化热评获取质量：自动剥离热评中的"作者赞过"、发布时间、IP 属地等干扰信息。
- 执行连续刷视频任务时，单条失败自动跳过继续看下一条，不再直接放弃整轮。

**观后感质量**

- 观后感由 Agent 基于视频转述和热门评论重新组织成符合自己人设的自然语言，不再照搬转述原文。
- 多条视频连看时，后续观后感自然衔接上一条内容，不再复读相同的开场白，保证体验连贯一致。

**性能优化**

- 远程部署时视频压缩移至远程主机执行并直接上传到转述 API，云服务器回归纯调度，单条全链路执行速度提升 4 倍，同时节约云服务器的流量与带宽成本。

### 修复项目

- 修复时长校验误杀短视频的 bug。
- 修复搜索页复用旧页面导致结果过期、"已经看过了"式复读的 bug。
- 修复大视频触发的压缩产物变量错误。
- 修复转述格式异常时直接报错的 bug——现降级为摘要继续，不中断对话。
- 修复压缩命令参数粘连导致压缩静默失败、回退慢速链路的隐性故障。

### 已知问题

- 时长未超限但体积超过下载上限的高码率短片，会全量下载后才被拒，待加体积预检。
- 视觉转述接口偶发格式抖动：已容错跳过、不中断对话，频率观察中（继承 1.0.0）。
- 分享判定的理由偶发过度脑补对方状态，待注入真实用户画像。
## 1.0.0——独立分支首个大版本

自上游 astrbot_plugin_douyin_dm 分出后的首个独立版本，以下为相对上游基线的全部增量。

### 新增功能

**视频与内容理解**

- 新增聊天图片理解：抖音私信中对方发送的图片会作为原生图像交给模型理解，常见图片形态均可识别。
- 新增读评论：视频观看后自动读取热门评论，一并交给聊天模型讨论。

**互动能力**

- 新增点赞：Agent 可根据自身人设自主点赞，也可按用户指令为指定视频点赞。
- 新增短链识别：用户可在其它平台向 Agent 发送 v.douyin.com 短链来分享抖音视频。
- 新增卡片化分享：支持把视频以卡片形式分享到指定联系人的抖音私信；除用户明确要求外，私信内不再以裸链接形式分享视频。

**自主刷抖音**

- 新增仿真人行为判断：Agent 像真实用户一样，自主为感兴趣的视频点赞，把好友可能感兴趣的视频分享给对方。
- 设置安全阈值：单次主动任务最多浏览 12 条视频或持续 20 分钟，到限自动停止，防止无限刷下去。
- 新增观看历史记录：Agent 被问到以前刷到过的视频时能如实回答，不再"失忆"。

**远程浏览器**

- 新增远程浏览器模式：浏览器可运行在另一台主机上，插件远程驱动——低配云服务器（2 核 2G 即可）也能稳定运行，浏览器与视频处理的资源消耗不落在服务器上。
- 配套一键部署脚本与部署文档（见产品文档·远程浏览器部署指南）。

**主动消息**

- 新增跨平台防撞车机制：防止抖音与其它平台在同一时间向用户发送主动消息，避免消息轰炸。

### 优化项目

**群聊与消息行为**

- 优化连续刷视频的回复机制：此前 Agent 连续看多条视频要全部刷完才统一回复，等待时间长、单条回复也过长；现在每看完一条就分享并讨论一条，逐条结清，指令刷视频与自主刷视频两个场景的体验均得到提升。
- 优化用户插话的响应机制：此前 Agent 连续刷视频时用户插话会被无视，直到刷完才回复；现在优先回应用户插话，再继续观看。
- 优化视频挑选逻辑：Agent 不再打开"视频不存在"的页面，并自动跳过已看过的视频。

**运行稳定性**

- 新增浏览器页面生命周期管理：多个操作涉及同一视频时自动复用同一页面，不重复打开；视频页闲置 3 分钟自动回收，避免异常残留的页面持续占用 CPU 与内存；视频页在后台打开，不占用聊天页前台。
- 新增孤儿页回收机制：空闲时自动关闭非聊天、非视频会话、非验证保留的孤儿页面，并带有防误收在用页机制。
- 优化故障诊断：故障自带现场诊断信息，便于排障。
- 优化 WebUI 报错信息：将模糊报错改为明确的错误提示，便于定位问题。
- 优化程序健壮性：浏览器进程意外退出后自动重启并恢复当前私信会话，业务不中断。

### 修复项目

- 抖音已屏蔽绝大多数 DOM 事件导致页面点击不生效——已将点击方式改为模拟点击，确保自动操作正常运行。
- 修复长回复分段发送时丢段的 bug。
- 修复聊天页被视频页抢占前台的 bug。
- 修复视频转述格式抖动时被直接判定为失败的 bug——现加入容错机制，抖动时仍可正常识别。
- 修复主动消息不生效的 bug。

### 已知问题

- 视觉转述接口偶发格式抖动：自动跳过、不中断对话，频率观察中。
- 主动消息的修复目前通过修改主动消息插件代码实现：上游插件更新时补丁会被覆盖，可能导致 bug 复现，待后续版本根治。
- 主动消息长任务可能溢出到免打扰时段（低优先）。
